# Agent-Plus

一个增强型自治 Agent 项目，支持**任务规划、工具调用、异常自修正、记忆存储和状态可视化**。

它不是简单的预定义 workflow，而是围绕“**规划 → 执行 → 观察 → 反思 → 修正**”闭环来完成任务，适合作为 Agent 课程作业、实验项目或原型系统。

## 功能特性

- **任务规划（Plan-and-Execute）**
  - 自动把复杂任务拆解为多个可执行步骤。
- **推理执行（ReAct）**
  - 在执行过程中按需调用工具，并基于观察结果继续决策。
- **自我修正（Reflexion）**
  - 工具失败、信息不足或步骤卡住时，会分析原因并重规划。
- **外部环境交互**
  - 支持本地命令执行、文件读写、联网搜索、网页抓取。
- **轻量记忆**
  - 自动记录历史任务与结果，供后续任务参考。
- **状态可视化**
  - 输出 JSON trace 和 Mermaid 流程图，展示内部状态流转。

## 环境要求

- Python 3.10 及以上
- 可用的 OpenAI 兼容接口 openai>=1.30.0
- 能访问外部网络（若需使用 web_search / fetch_url）

## 安装

先克隆或进入项目目录，然后安装依赖：

```bash
pip install -r requirements.txt
```

## 环境变量配置

项目使用以下环境变量,使用前先在所在文件夹打开终端输入以下内容：

- `OPENAI_API_KEY`：模型服务 API Key
- `OPENAI_BASE_URL`：OpenAI 兼容接口地址
- `OPENAI_MODEL`：模型名称，默认 `gpt-4o-mini`

### Linux / macOS

```bash
export OPENAI_API_KEY="your_api_key"
export OPENAI_BASE_URL="your_base_url"
export OPENAI_MODEL="gpt-4o-mini"
```

### Windows PowerShell

```powershell
$env:OPENAI_API_KEY="your_api_key"
$env:OPENAI_BASE_URL="your_base_url"
$env:OPENAI_MODEL="gpt-4o-mini"
```

## 启动方式

### 默认模式（启用规划）

```bash
python zizhiagent1.0.py  "搜索 Python subprocess 的常见风险，并写一份简短总结"
```

### 关闭规划模式

```bash
python zizhiagent1.0.py  --no-plan "读取当前目录文件，并总结项目结构"
```

## 支持的工具

当前内置工具如下：

- `execute_bash`
  - 执行本地 bash 命令
- `read_file`
  - 读取本地文件内容
- `write_file`
  - 写入本地文件
- `web_search`
  - 进行外部网络搜索
- `fetch_url`
  - 抓取网页正文内容

## 运行流程

Agent 的核心执行流程如下：

```text
用户任务
  ↓
任务规划
  ↓
按步骤执行
  ↓
调用工具与环境交互
  ↓
观察结果
  ↓
失败则反思并修正
  ↓
输出最终结果
```

更具体地，可以概括为：

```text
Start
→ Plan
→ Execute Step
→ Reason
→ Act
→ Observe
→ Self-Correct
→ Replan（如失败）
→ Final
```

## 输出文件说明

程序运行后通常会生成以下文件：

### 1. `agent_memory.md`
用于存储历史任务与结果摘要，作为轻量长期记忆。

### 2. `agent_trace.json`
记录结构化状态流转信息，例如：

- 当前阶段
- 时间戳
- 工具调用
- 错误信息
- 反思与重规划记录

### 3. `agent_trace.mmd`
Mermaid 格式的状态图，可复制到 Mermaid Live Editor 中进行可视化。

## 设计亮点

### 1. 不只是固定 workflow
本项目不是预定义的死板流程，而是由模型动态生成计划、动态选择工具、动态修正策略。

### 2. 多推理框架融合
项目融合了三类常见 Agent 思路：

- **Plan-and-Execute**
- **ReAct**
- **Reflexion**

### 3. 面向外部环境
除了本地命令和文件系统操作，还支持联网搜索和网页抓取，更符合“与外部世界交互”的 Agent 定义。

### 4. 可观测性
通过 trace 文件和 Mermaid 图，能够清晰展示 Agent 的内部状态流转过程，便于调试、答辩和展示。

## 安全说明

本项目包含 `execute_bash` 工具，请谨慎使用。虽然程序中可以加入危险命令拦截规则，但仍建议：

- 在受控目录中运行
- 避免使用高权限账号执行
- 对工具执行范围进行白名单限制
- 不要在生产环境直接开放命令执行能力

## 常见问题

### 1. 运行时报错：`ModuleNotFoundError: No module named 'openai'`
请先安装依赖：

```bash
pip install -r requirements.txt
```

### 2. 模型调用失败
请检查：

- `OPENAI_API_KEY` 是否正确
- `OPENAI_BASE_URL` 是否可访问
- `OPENAI_MODEL` 是否存在
- 当前网络是否正常

### 3. `web_search` / `fetch_url` 无法访问某些网站
部分网站有反爬或访问限制，建议优先测试公开网页。
