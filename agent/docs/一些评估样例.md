使用建议
数据集	推荐评测方法	预计结果

面向结果

视模型能力，通常 3/4 通过

联合评估-代码执行验证

最严格，需输出 + 过程均正确

面向结果
sec-subprocess/sec-network 会触发安全 flag，risk_band 为 medium
操作步骤：

进入「评测中心」→「任务管理」
将上方任意 JSON 粘贴到「粘贴 JSON 创建」框，点「解析并创建」
在「新建评测任务」中选择数据集 + 评测方法，点「创建任务」
点「启动」开始跑批，完成后点「明细」查看每条结果的 Token、耗时、安全等级等指标
