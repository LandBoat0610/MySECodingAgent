# 评测端到端跑通示例

按顺序操作即可完成：**数据集 → 评测任务 → 启动 → 查看明细/回放 →（可选）图表与删除**。  
前提：后端已启动（如 `uvicorn agent.main:app --port 8000`），前端已启动（如 `npm run dev`），并已配置可用的 **`OPENAI_API_KEY`**（评测线程内 Agent / Ragas / Judge 均依赖）。

---

## 一、最小数据集 JSON（可直接粘贴）

在评测中心 **任务管理** → **代码测试集** → 展开 **「最小可运行 JSON 示例」**，点 **填入粘贴框**，再点 **解析并创建**。  
或手动将以下内容保存为 `.json` 上传。

```json
{
  "name": "端到端演示数据集",
  "items": [
    {
      "id": "demo-q1",
      "description": "请只用一行回答：17 加 25 等于多少？只输出数字，不要其它文字。",
      "expected_output": "42",
      "test_cases": []
    }
  ]
}
```

字段说明：

| 字段 | 必填 | 说明 |
|------|------|------|
| `name` | 否 | 数据集名称；也可在界面「名称」输入框填写 |
| `items` | 是 | 非空数组 |
| `items[].description` 或 `task` | 是 | 送给 Agent 的任务描述 |
| `items[].expected_output` | 否 | 面向结果评测时用于比对答复 |
| `items[].test_cases` | 否 | `{ "input", "expected" }` 数组，可为 `[]` |
| `items[].id` | 否 | 不写则用索引 |

含 **多条** 样本时，在 `items` 中追加对象即可。

## 二、推荐操作流程（约 5～10 分钟）

1. **工作区**  
   用左下角 **「IDE｜评测中心」** 进入 **评测中心** → **任务管理**（`/workspace/evaluation/tasks`）。

2. **Agent 配置（快照）**  
   在页面顶部填写 **模型 ID**（如 `gpt-4o-mini`）、**版本标签**，点 **保存为当前 IDE 配置**。  
   后面新建的评测任务会 **快照** 此时的模型。

3. **创建数据集**  
   - 推荐：点示例区的 **填入粘贴框** → **解析并创建**。  
   - 或：**上传** 上面的 JSON 文件。

4. **新建评测任务**  
   填写任务名称，选择刚创建的数据集，选 **面向结果** 或 **面向过程**，点 **创建任务**。

5. **启动**  
   在任务列表对该任务点 **启动**。状态变为 `running`，进度会递增；列表约每 3 秒刷新。  
   等待变为 `completed`（或失败看列表侧后端日志）。

6. **看结果**  
   - **明细**：查看每条是否通过、摘要；点 **回放** 可看轨迹与安全扫描。  
   - **图表可视化**：选该任务看雷达图均值。

7. **删除（按需）**  
   - **评测任务**：点 **删除**，确认后删除任务及全部结果（运行中须先 **取消**）。  
   - **数据集**：若仍有任务引用，默认会拒绝删除；勾选 **「删除数据集时…一并删除关联任务」** 再删，可 **级联删除** 非运行中的任务后再删数据集。

---

## 三、常见问题

- **删除数据集提示仍有关联任务**：勾选页面表格下方的 **一并删除关联评测任务**，或先手动删掉各评测任务。  
- **运行很慢或指标为空**：检查 Key、模型名、网络；单条简单算术题通常仍能跑通 Agent 全流程，只是耗时取决于模型。  
- **刷新页面**：请使用 **`/workspace/...`** 路径；详见 `评测中心使用说明.md`。
