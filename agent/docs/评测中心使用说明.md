# 评测中心使用说明

本文说明如何在 **单页应用（SPA）** 中使用 IDE 与 **评测中心**。应用只有一个 `#app` 壳：**默认路由为 `/workspace/ide`**；评测相关页面为 **`/workspace/evaluation/...`**。后端 REST API 仍为 **`/eval/...`**（开发代理转发），与页面路径区分，避免刷新时被误判为 API。

## 一、如何切换 IDE 与评测中心

1. 启动后端与前端（如 `npm run dev`）。
2. 在浏览器 **预览区左下角附近**（侧栏右沿旁）使用 **`IDE | 评测中心`** 分段按钮：
   - 左侧 **IDE**：编码界面（项目、文件树、预览、Agent 对话）。
   - 右侧 **评测中心**：数据集与评测任务、指标与图表等。
3. **仅此一处**切换两大工作区（侧栏不再提供评测入口）。评测页顶栏的 **「← IDE」** 与按钮等价，跳回 **`IDE`** 命名路由。
4. 首次访问站点根路径 **`/`** 会自动跳到 **`/workspace/ide`**。

> **说明**：「实时评测」面板仍在 IDE **左侧栏底部**，展示当前会话与 Agent 交互的耗时、Token、工具调用等；切换到评测中心后左侧栏卸载，数据以后端快照为准；回到 IDE 后可继续观察。

## 二、功能总览

| 模块 | 前端路由 | 作用 |
|------|----------|------|
| 任务管理 | `/workspace/evaluation/tasks` | 配置 Agent 模型快照、管理数据集与评测任务、启停跑批、查看单条结果与 **过程回放 / 安全评估** |
| 指标看板 | `/workspace/evaluation/metrics` | 查看评测任务数量、运行状态、通过/未通过汇总 |
| 对比分析 | `/workspace/evaluation/compare` | 选择两次已完成任务，按条目并排对比是否通过 |
| 图表可视化 | `/workspace/evaluation/charts` | 单次任务雷达图、两次任务的柱状对比（聚合 Ragas、Judge、运行时与安全等维度） |

后端接口示例：`GET /eval/tasks`、`GET /eval/tasks/{id}/analytics`（前端 axios 仍请求 `/eval/...`，与浏览器地址栏路径无关）。

为兼容旧书签，访问 **`/evaluation/...`** 会自动 **重定向** 到对应的 **`/workspace/evaluation/...`**。

从「建数据集」到「启动评测」的逐步说明与可复制 JSON，见同目录 **`评测端到端跑通示例.md`**。

## 三、任务管理（核心流程）

### 1. Agent 版本配置

- 在 **「Agent 版本配置」** 中填写 **模型 ID**、**版本标签**，保存后作为「当前 IDE 配置」。
- **新建评测任务** 时会 **快照** 当时的模型与标签；实际推理在后台评测线程中使用该快照，与你在 IDE 里随后改的模型可以不同。

### 2. 代码测试集（数据集）

- **上传 JSON 文件** 或 **粘贴 JSON** 创建数据集。
- 典型结构示例：

```json
{
  "name": "可选数据集名",
  "items": [
    {
      "id": "可选",
      "description": "给 Agent 的自然语言任务描述",
      "expected_output": "可选，面向结果评测时参考",
      "test_cases": []
    }
  ]
}
```

- 上传后可在列表中 **删除** 不需要的数据集。

### 3. 新建与运行评测任务

- 填写 **任务名称**，选择 **数据集**。
- **评测方法**：
  - **面向结果**：侧重最终答复与预期的一致性（及评分逻辑中的其它条件）。
  - **面向过程**：在评分策略上更强调过程约束；**两种方式都会持久化完整执行轨迹** 与安全扫描结果，便于在明细里 **回放**。
- 点击 **「启动」** 后，后端按顺序对每条样本调用与 IDE 相同的 LangGraph Agent，结果写入数据库。运行中列表会周期性刷新。
- **「取消」** 可中断正在运行的任务；**「删除」** 需在非 running 状态下使用。

### 4. 单条结果：回放与安全

- 在任务列表中点击某任务的 **「明细」**。
- 表格中每一行可点 **「回放」**，查看：
  - **思考路径与状态**：按时间排列的 `phase`、内容、以及精简的 **状态轮廓**（如当前任务、目标文件等）。
  - **安全评估（启发式）**：对最终答复与工作区内少量改动文件的离线规则扫描，给出 **风险分 0–10**、等级与 **flags**（仅供演示与初审，不能替代专业安全审计）。

> **提示**：若某列显示「旧数据或未写入」，请 **重新启动** 一次该评测任务以写入新字段。

## 四、图表可视化

- **单次任务 · 雷达图**：选择已完成的任务，查看多条样本在各维度上的 **均值**（含 Ragas、Judge、工具成功率、Token 效率、**代码安全** 等，具体以后端聚合为准）。
- **双任务对比 · 柱状图**：选择两个任务后 **「加载对比」**，对比两侧均值。

## 五、环境变量（与评测质量相关）

在部署环境中可配置（示例，名称以你 `.env` 与代码为准）：

- **`OPENAI_API_KEY`**：Agent、Ragas、LLM-as-Judge 等需要。
- **`JUDGE_MODEL`**：可选，指定裁判模型；不填则使用当前生效模型。
- **`RAGAS_LLM_MODEL` / `RAGAS_EMBED_MODEL`**：可选，用于 Ragas 指标。

缺少 Key 时，部分指标可能为空或雷达维度偏低，但不影响任务列表与轨迹回放（轨迹依赖 Agent 实际运行）。

## 六、实时评测面板（IDE 左侧栏）

- **位置**：仅在 **IDE** 工作区显示：左侧栏 **最底部**（「实时评测」可折叠）。
- **切换评测中心**：使用 **预览区左下角附近** 的 **`IDE | 评测中心`** 按钮（与侧栏底部对齐、互不遮挡）；勿依赖旧版侧栏链接。评测页顶栏 **「← IDE」** 等价于切回 IDE。
- **内容**：本轮耗时、累计 Token、轨迹步数、工具调用次数、工具成功率与平均耗时（来自 WebSocket 推送的 runtime 摘要及会话快照）。
- **交互**：点击「实时评测」标题栏可折叠/展开；Agent 开始运行时会自动展开。

## 七、常见问题

1. **以前在评测中心刷新会变成一堆 JSON 或空白页？**  
   这是因为开发环境下 Vite 把 **`/eval/*`** 代理到了后端，若浏览器地址曾是 **`/eval/tasks`** 会与 API 路径冲突。当前页面统一使用 **`/workspace/evaluation/...`**；**`/evaluation/...`** 仅作 **重定向** 到上述路径。请勿把 SPA 页面做成与 **`/eval/*`** API 同路径。

2. **进入评测中心后实时数据不涨了**  
   「实时评测」挂在 IDE 布局上；用预览区左下角按钮切回 **IDE** 并继续会话后，会随新一轮运行更新。

3. **雷达图全零或很少维度**  
   多为 Ragas/Judge 未成功调用（网络、Key、模型名错误）；可查看后端日志与单条结果中的 JSON 字段。

4. **安全分偏高**  
   启发式规则会匹配常见危险写法与疑似密钥样式，可能存在误报；以人工复核为准。
