# 迭代三 Agent 产品化要求

来源：2026 软工三迭代三任务说明中关于 Agent 产品化和能力优化的要求整理。

## 基本需求点

Agent 平台需要支持用户管理对话。用户应能创建、查看、切换和删除对话或会话，并能在对话中查看 Agent 的执行过程、计划、工具调用和最终结果。

Agent 平台需要支持用户管理工具。用户应能查看 Agent 可用工具列表，并能启用或禁用具体工具，使 Agent 的执行能力可配置、可观察。

## 加分需求点

平台可以支持跨对话知识共享。Agent 能把不同对话中的项目偏好、历史经验、常用命令和问题修复记录沉淀为可复用上下文，并在后续对话中检索和使用。

平台可以支持向 Agent 添加 skill。用户可以创建、编辑、启用或删除自定义 skill，让 Agent 在代码审查、知识库问答、安全检查等特定场景中遵循更明确的执行规范。

## 评测关注点

RAG 问答样例应能回答：

- 基本需求点包括对话管理和工具管理。
- 加分需求点包括跨对话知识共享和添加 skill。
- 回答应尽量说明来源来自迭代三任务说明或其整理文档。
